# DaoDrift

DaoDrift leverages cloud-based streaming and event-driven architecture to orchestrate data streams through a scalable processor pipeline.

DaoDrift is built to be simple and practical, focusing on doing one thing well.

**Why DaoDrift?**

- DaoDrift leverages cloud-based streaming and
- event-driven architecture to orchestrate data
- streams through a scalable processor

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoDrift.git`
2. `cd DaoDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DaoDrift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
